# Supabase Setup (Polymarket Dashboard)

## 1) Required environment variables

Set these in Vercel Project Settings → Environment Variables:

- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`

> `SUPABASE_SERVICE_ROLE_KEY` is server-only secret. Never expose it in frontend code.

## 2) Create `trades` table

Run this SQL in Supabase SQL editor:

```sql
create table if not exists public.trades (
  id bigint generated by default as identity primary key,
  strategy text,
  timeframe text,
  market text,
  side text,
  status text,
  entry_price numeric,
  exit_price numeric,
  pnl numeric,
  entry_time timestamptz,
  exit_time timestamptz,
  created_at timestamptz default now()
);

create index if not exists idx_trades_entry_time on public.trades(entry_time desc);
create index if not exists idx_trades_created_at on public.trades(created_at desc);
```

## 3) API behavior

`/api/trades` now reads from Supabase first.
If Supabase is unavailable/misconfigured, it falls back to local `trades.json`.

## 4) Verify

- Open `/api/trades` in browser and confirm JSON response.
- Open dashboard and verify rows populate.
- Push to GitHub and confirm Vercel deployment.
